The first layer is the Resident layer, which allows residents of Antique to access the system through the Resident Progressive Web Application (PWA) using a device with an internet connection. Residents log in, provide incident details and GPS coordinates, upload supporting photographs, and submit an SOS fire report. The backend validates and processes the submission, stores report information in the centralized database, and saves uploaded files in private storage. Residents receive a reference number and can monitor the status of their reports.

Secondly, the Municipal BFP Personnel layer allows authorized personnel to access the Municipal Dashboard through secure login credentials. Personnel review submitted fire reports and preliminary severity assessments based on weather conditions and incident factors. They verify incident information, assign responders, manage dispatch activities, and record incident resolution. When additional resources are needed, personnel can submit backup requests and monitor the decisions of receiving municipalities. These actions pass through the backend and are recorded in the centralized database.

Thirdly, the Firefighter layer allows authorized field responders to access dispatch assignments through the Firefighter App. The application provides incident information and road routes based on location coordinates to assist responders in reaching the reported fire. Responders send route-start and GPS updates through the application, allowing authorized BFP personnel to monitor response progress. The backend processes these updates and maintains the associated response records.

Lastly, the Provincial BFP Personnel layer allows authorized personnel to access the Provincial Dashboard for province-wide incident monitoring and records management. Personnel view incident information and summaries, review coordination activities, and perform permitted record updates and approvals. Changes are submitted through the backend, where access permissions are checked before records are updated.

The four user components connect through the Backend API, which handles validation, authorization, and processing. The PostgreSQL database stores reports, user information, dispatch assignments, and other operational records, while private storage holds photographs and identification files. Authentication controls access according to user roles, and notification services deliver system updates through configured channels. Final decisions concerning incident assessment, dispatch, assistance requests, and response operations remain under the authority of authorized BFP personnel.
