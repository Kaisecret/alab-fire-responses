# BFP Responsive Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a polished, accessible, responsive ALAB fire-response hero in `BFP/index.html` using the supplied image assets and sans-serif typography.

**Architecture:** Keep the static deliverable self-contained in one HTML file with semantic markup, internal CSS, and a small navigation/depth-effect script. Add one dependency-free Node test file that validates the required content, assets, accessibility hooks, responsive rules, and reduced-motion support.

**Tech Stack:** HTML5, CSS3, vanilla JavaScript, inline SVG, Node.js built-in test runner, headless Chrome for rendering checks.

## Global Constraints

- Render only one full-width hero section and its header.
- Use `images/bg images.png`, `images/Logo.png`, `images/phone.png`, and `images/BFPBACK.png`.
- Use `images/Hero section.png` only as a visual reference.
- Use only sans-serif typography and no network-hosted dependencies.
- Preserve the approved navigation, headline, body copy, and action labels verbatim.
- Provide desktop, tablet, and mobile layouts without horizontal overflow.
- Make the mobile navigation keyboard-accessible and expose `aria-expanded`.
- Honor `prefers-reduced-motion: reduce`.
- The workspace is not a Git repository, so commit steps are intentionally omitted rather than initializing repository state outside the requested scope.

Add the interaction script:

```html
<script>
  const menuButton = document.querySelector('.menu-toggle');
  const navigation = document.querySelector('.site-nav');
  const setMenu = (open) => {
    navigation.classList.toggle('is-open', open);
    menuButton.classList.toggle('is-open', open);
    menuButton.setAttribute('aria-expanded', String(open));
    menuButton.setAttribute('aria-label', open ? 'Close navigation menu' : 'Open navigation menu');
  };
  menuButton.addEventListener('click', () => setMenu(menuButton.getAttribute('aria-expanded') !== 'true'));
  navigation.addEventListener('click', (event) => {
    if (event.target.closest('a')) setMenu(false);
  });
  document.addEventListener('keydown', (event) => {
    if (event.key === 'Escape') {
      setMenu(false);
      menuButton.focus();
    }
  });
  window.addEventListener('resize', () => {
    if (window.innerWidth > 900) setMenu(false);
  });
</script>
```
